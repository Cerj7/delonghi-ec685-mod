# Quickstart: Descaling Program validation

End-to-end перевірка після імплементації delta в `011` + `013`. Контракти: [descale-fsm.md](./contracts/descale-fsm.md), [panel-hold-uart.md](./contracts/panel-hold-uart.md), [descale-tunables.md](./contracts/descale-tunables.md). Модель: [data-model.md](./data-model.md).

## Prerequisites

1. Arduino IDE + бібліотеки з `readme.md`.
2. Панель з оновленим `scripts/011_button_panel_ui.cpp` (`B3` + `R3`).
3. Основна з оновленим `scripts/013_main_brew_logic.cpp` (descale FSM).
4. Лінк D6↔D9, D5↔D8, GND; ручка пари; флоуметр; OLED.
5. USB Serial основної: **115200**.
6. `FLOW_PULSES_PER_ML > 0` (калібрування) **або** тимчасово зменшений `DESCALE_PHASE_VOLUME_ML` під відомий об’єм стенду.
7. Для швидких прогонів MAY зменшити `DESCALE_HOLD_ENTER_MS` / phase volume — лишайте зміни лише в Tunables.

## Setup

1. Залити `011`, потім `013`.
2. Відкрити Serial Monitor основної (логи `B3`/`R3`/`DC0` за наявності).
3. Переконатись, що машина не в brew/steam/`FAULT` (типово `ESPRESSO_READY`).

## Scenarios

### S1 — Коротке «пар» без входу (P1)

1. З готовності натиснути «пар» < 1 с і відпустити.
2. Очікувано: **немає** OLED-відліку декальцинації; спрацьовує штатний пар (`001`).
3. Повторити з неактивним `DC1` і з активним (force/`DECALC_INTERVAL_S`) — short path однаковий.

### S2 — Відлік і cancel (P1)

1. Утримувати «пар» ≥1 с.
2. Очікувано: OLED «Режим декальцинації через N сек», N зменшується.
3. Відпустити до 10 с.
4. Очікувано: відлік зник; програма **не** стартувала; пар **не** стартував (cancel hold).

### S3 — Вхід у prep з/без `DC1` (P1)

1. Утримувати «пар» ≥10 с (±200 мс) — прогін з `DC1` і прогін без.
2. Очікувано: OLED prep (1 л очисника, відкрити ручку, «пар»); помпа 0 %; ТЕН 0 %.
3. Натиснути «пар» при **закритій** ручці → фаза не стартує; пояснення на OLED.
4. Відкрити ручку, коротко «пар» → `DESCALE_PHASE1`, текст фази очистки; ТЕН лишається 0 %.

### S4 — Фаза 1: імпульси, refill, завершення (P1)

1. Під час фази 1 перевірити 500 / 1000 мс (±50 мс) @ 100 %.
2. Симулювати раннє спорожнення (мало рідини): no-flow під час ON → OLED доливу; `DC1` не скидається; після доливу + «пар» (ручка відкрита) volume продовжується.
3. Досягти цілі об’єму (або no-flow при вже ≥ цілі) → OLED «Залийте 1 л води…»; `DC1` активний.

### S5 — Фаза 2 і `DC0` (P1)

1. З wait-rinse: закрита ручка + «пар» → відмова з поясненням.
2. Відкрита ручка + «пар» → промивання; імпульси 500 / 500 (±50 мс); ТЕН 0 %.
3. Досягти цілі або no-flow P2 → протягом ≤1 с кадр `DC0`, LED4 гасне, uptime-інтервал обнулено; машина поза програмою.
4. Негатив: обірвати живлення на фазі 1 або 2 → після старту **немає** auto-resume; `DC1` лишається (якщо був / якщо фаза 2 не завершилась).

### S6 — Ігнор brew-кнопок і ручка mid-phase (P2)

1. Під час фази 1/2 натиснути `B1`/`B2` → cold flush / еспресо **не** стартують.
2. Закрити ручку під час імпульсів → фаза **не** завершується лише через це; імпульси тривають до volume/no-flow/refill.

### S7 — USB `DC0` лишається (P3)

1. Поза програмою (або після abort) надіслати USB `DC0`.
2. Очікувано: як у `001` — панель `DC0` + clear EEPROM-інтервалу (FR-019).

### S8 — `FAULT` під час програми

1. Симулювати невалідну термопару / cutoff під час фази.
2. Очікувано: ТЕН/помпа OFF; без `DC0`; програма перервана.

## Pass criteria (summary)

| ID | Check |
| --- | --- |
| SC-001 | Hold 10 с → prep з/`без` DC1; early release ніколи не стартує програму |
| SC-002 | ТЕН 0 % у всій програмі |
| SC-003 | Таймінги імпульсів фаз |
| SC-004 | Refill без скидання DC1 |
| SC-005 | Success → DC0; abort → без DC0 |
| SC-006 | Ручка закрита блокує старт фаз |
| SC-007 | Немає magic numbers поза Tunables (рев’ю) |
