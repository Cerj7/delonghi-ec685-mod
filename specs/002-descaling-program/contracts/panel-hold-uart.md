# Contract: Panel hold UART (delta)

Дельта до [`docs/button-panel-protocol.md`](../../../docs/button-panel-protocol.md) і [`../../001-main-brew-logic/contracts/panel-uart.md`](../../001-main-brew-logic/contracts/panel-uart.md).

Мета: дати основній платі вимірювати утримання «пар» без того, щоб панель вирішувала режим (FR-018).

## Framing (без змін)

| Параметр | Значення |
| --- | --- |
| UART | 8N1, 19200 |
| Кадр | ASCII ≤ `LINK_CODE_MAX_LEN` (3) + `\n` |
| Лінії | як у базовому протоколі |

## Ingress (панель → основна)

| Код | Коли | Значення |
| --- | --- | --- |
| `B1` | Rising edge «1» | без змін |
| `B2` | Rising edge «2» | без змін |
| `B3` | Rising edge «пар» | Початок натискання «пар» |
| `R3` | Falling edge «пар» | Відпускання «пар» (**нове**) |

### Правила панелі (`011`)

1. Debounce press/release лишається локальним.
2. На підтверджений press «пар» → надіслати `B3` (як зараз).
3. На підтверджений release «пар» → надіслати `R3`.
4. `B1`/`B2`: v1 **без** обов’язкового release-коду (не потрібні для декальцинації).
5. Панель **не** вимірює 1 с / 10 с і **не** шле `H3`/`D3` як «вхід у декальцинацію».

### Правила основної (`013`)

1. Парсити `R3` так само, як інші ≤3-символьні коди.
2. Інтерпретація hold — лише на main (див. [descale-fsm.md](./descale-fsm.md)).
3. Короткі підтвердження всередині програми (старт фази / resume після refill) використовують **`B3`** (press); `R3` у `DESCALE_PREP`/`REFILL`/`WAIT_RINSE`/`PHASE*` ігнорувати.
4. У станах brew/steam/`FAULT` поведінка `B3` лишається за матрицею `001`; `R3` без активного hold-жесту — no-op.

## Egress (основна → панель)

Без нових кодів. Успіх програми → існуючий `DC0`. Нагадування → існуючий `DC1` з uptime-логіки `001`.

## Compatibility

| Споживач | Вимога |
| --- | --- |
| Стара панель без `R3` | Hold-enter **неможливий**; short `B3` може лишитись press-immediate — не підтримується для `002` |
| Нова панель + стара основна | Зайві `R3` ігноруються (невідомий код / no-op) — brew/steam не ламаються, якщо main ігнорує невідоме |
| Обидві оновлені | Повна семантика short vs hold |

Імплементація `002` **SHALL** оновити обидві прошивки разом.
