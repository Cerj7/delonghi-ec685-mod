# Pot Pump + Thermoblock Display (`scripts/005_pot_pump_temp_display.cpp`)

Прошивка-стенд для Arduino Nano: потенціометр помпи (`A0`) напряму задає потужність помпи через AC-диммер, на OLED — температура термоблоку й **поточна** потужність помпи. ТЕН **не вмикається ніколи**, кнопки **не зчитуються**.

| Пункт | Реалізація |
| --- | --- |
| Дисплей | Рядок 1: `Tt=` (термоблок, MAX6675 CS = `A2`); рядок 2: `P=nn%` |
| ТЕН | `D4` = `OUTPUT` + `LOW` у `setup` і **кожен** `loop` |
| Помпа | `A0` → 0…100 % → рівень диммера за RMS-кривою |
| Термопара бачка | MAX6675 #2 (CS = `D11`) **не читається**, але CS тримається `HIGH` |
| Кнопки / ручка пари | Не зчитуються, лінії = `INPUT_PULLUP` |
| Потенціометр температури (`A1`) | Не читається |
| Watchdog | 2 с: зависання → reset → актуатори в безпечному стані |

## Піни

| Пін | Роль у цій прошивці |
| --- | --- |
| `D2` | Zero-Cross диммера (жорстко всередині `AC_Dimmer`, INT0) |
| `D3` | GATE диммера → симистор помпи |
| `D4` | SSR ТЕНу — завжди `LOW` |
| `D5` | флоуметр — не використовується (вхід з підтяжкою) |
| `D6` | штатний SDD — не використовується (вхід з підтяжкою) |
| `D8` / `D9` | Кнопка 1 — не використовуються (входи з підтяжкою, Arduino їх не штовхає) |
| `D10` | ручка пари — не використовується (вхід з підтяжкою) |
| `A2` | CS термопари **#1 — термоблок / вихід** (читається і показується) |
| `D11` | CS термопари **#2 — бачок** (не читається, але примусово `OUTPUT` + `HIGH`) |
| `D12` / `D13` | SO / SCK — спільна шина MAX6675 |
| `A0` | **потенціометр помпи** (0…100 %) |
| `A1` | потенціометр температури — не читається |
| `A4` / `A5` | OLED I2C (SDA / SCL) |

> Термопари **поміняні місцями** відносно ранніх скетчів: тепер термоблок на `A2`, бачок на `D11`.
>
> ⚠️ **CS бачка (`D11`) не читається, але обов'язково тримається `OUTPUT` + `HIGH`.** Обидва MAX6675 висять на спільній шині SO (`D12`). Якщо CS другого модуля лишити «плаваючим» входом, він може випадково опинитися в `LOW` — і тоді **обидва** модулі одночасно виганяють дані на SO. Шина конфліктує, перший модуль читає всі нулі, і `readCelsius()` повертає рівно `0.0` (а не `NAN`, бо біт обриву термопари теж нульовий). Саме тому `readCelsius()` на другому модулі — читання «нулів» — так і виглядає: 0 градусів замість кімнатних 20–25 °C.

Повна таблиця pinout — у [`readme.md`](../readme.md).

## Поведінка

### Потенціометр → помпа

- Опитування кожні **20 мс**: 8 відліків АЦП, середнє → 0…100 %.
- Експоненційне згладжування (`POT_SMOOTHING = 0.3`) — без нього АЦП-шум смикає фазу симистора й цифри на екрані.
- Гістерезис `DIMMER_HYSTERESIS = 2` рівня диммера: дрібні коливання не переписують фазу щоразу.
- Стартова позиція застосовується одразу в `setup` — без «розгону» з нуля.

**Проценти — це частка потужності (RMS), а не «шкала диммера».** Фазовий диммер нелінійний: рівень `180` дає ≈85 % потужності, а `120` — лише ≈45 %. Перетворення робить `powerPercentToDimmerLevel()` за оберненою RMS-кривою (константи `ZERO_VAL = 19850`, `K = 77` з `AC_Dimmer.cpp`):

| Потужність, % | Рівень диммера |
| --- | --- |
| 0 | 0 |
| 10 | 65 |
| 25 | 94 |
| 50 | 128 |
| 75 | 162 |
| 90 | 191 |
| 100 | 240 |

Крива **електрична**: гідравлічна продуктивність вібраційної помпи додатково нелінійна, тож фактичний потік на 50 % може бути зовсім не вдвічі меншим. Калібруйте за [`dimmer.md`](dimmer.md), за потреби правте таблицю.

### ТЕН

- `D4` = `OUTPUT` + `LOW` у `setup` до ініціалізації диммера й OLED, і повторно кожен `loop`.
- Ніякої логіки нагріву немає: `D6` (SDD) не читається, PID/feed-forward відсутні.

### Кнопки

Не зчитуються. Лінії `D8`/`D9` лишаються `INPUT_PULLUP` (у пасивному стані, Arduino їх не тягне в `LOW`), тому штатна матриця кавоварки не заважається взагалі.

### Watchdog

`wdt_enable(WDTO_2S)` у `setup`, `wdt_reset()` на початку `loop`. Зависання → reset → `D4` LOW, диммер у `setup` скидається на 0 і одразу виставляється за потенціометром. `MCUSR = 0; wdt_disable();` на початку `setup` прибирає цикл перезавантажень після watchdog-reset.

## Serial (115200)

```text
# EC685 pot-pump + thermoblock display (heater permanently OFF)
# t_ms,Tt_C,pump_pct,dimmer_0_255
5120,93.50,75,162
5620,93.25,75,162
6120,93.25,40,115
```

| Поле | Опис |
| --- | --- |
| `t_ms` | `millis()` |
| `Tt_C` | температура термоблоку, `nan` = помилка зчитування |
| `pump_pct` | поточна (згладжена) потужність помпи, 0…100 |
| `dimmer_0_255` | фактично застосований рівень диммера (0…240) |

Зручно для перевірки: `dimmer_0_255` має змінюватися плавно при обертанні потенціометра й **не** смикатися сам по собі.

## Типові проблеми

| Симптом | Ймовірна причина | Що зробити |
| --- | --- | --- |
| `Tt=---` | Термопара не на `A2`, обрив, немає живлення модуля | Перевірити `A2`/`D12`/`D13`, VCC/GND, холодний спай |
| `Tt=0.0` постійно (не `---`) | CS другої термопари (`D11`) «плаває» → конфлікт на шині SO | Перевірити, що `D11` = `OUTPUT` + `HIGH` (у `setupUnusedPins()`); у Serial буде `# WARN Tt=0.0` |
| `Tt` показує кімнатну температуру при гарячому блоці | Модулі переплутані місцями | Поміняти CS `A2` ↔ `D11` або поміняти модулі фізично |
| Показник % стрибає на кілька одиниць | Шум АЦП / довгі дроти до потенціометра | Зменшити `POT_SMOOTHING` (напр. 0.15), підняти `POT_SAMPLES`, додати 100 нФ на движок |
| Помпа гудіє, але не качає | Рівень нижче порога спрацьовування | Перевірити на 60–100 %; див. `dimmer.md` про dead zone |
| Помпа крутиться завжди | Zero-Cross `D2` не підключений / диммер без живлення | Перевірити `D2` та живлення диммера |
| OLED чорний, у Serial `# OLED init failed` | Адреса не `0x3C`, `A4`/`A5` переплутані | I2C scanner |
| Перезавантаження кожні 2 с | Спрацював watchdog: `loop` довше 2 с | Перевірити I2C-шину OLED |

## Безпека

> ⚠️ 220 В AC.
>
> 1. Прошити й перевірити **без** силового живлення диммера та ТЕНу: у Serial `pump_pct`/`dimmer_0_255` мають плавно змінюватися від потенціометра, на OLED — температура.
> 2. Мультиметром: на `D4` завжди 0 В.
> 3. Лише потім підключати диммер і SSR під наглядом.
>
> Штатний алгоритм керування ТЕНом цією прошивкою **не дублюється** — машина в цьому режимі не гріється. Це стенд, а не робоча прошивка кавоварки.
