# Режими роботи штатної прошивки PIC16F1938 (DeLonghi EC685)

Аналіз декомпіляту [`assets/DedicaEC685_PIC16F1938_hex.c`](../assets/DedicaEC685_PIC16F1938_hex.c) (оригінальна прошивка MCU `PIC16F1938`).  
Точка входу головного циклу: `FUN_CODE_080c` (рядок ~2409).

> Це **не** опис Arduino-репліки `013_main_brew_logic.cpp`. Значення нижче взяті з штатного C-декомпіляту. Оцінки в °C і переведення тіків у секунди позначені окремо.

---

## 1. Ключові змінні FSM

| Змінна | Роль |
| --- | --- |
| `DAT_DATA_004f` | Основний режим машини |
| `DAT_DATA_004d` | Підстан / крок усередині режиму |
| `DAT_DATA_002b:002a` | Поточна температура (10-біт ADC, NTC) |
| `DAT_DATA_002f:002e` | Уставка / цільова температура (10-біт ADC) |
| `DAT_DATA_0031:0030` | Лічильник прогресу помпи (інкремент під час роботи) |
| `DAT_DATA_00ba:00b9` | Ціль зупинки помпи (порівнюється з `0031:0030`) |
| `DAT_DATA_0035:0034` | Окремий countdown-таймер режиму (декремент у тіку FSM) |
| `DAT_DATA_0037` | `0` = 1 чашка, `1` = 2 чашки |
| `DAT_DATA_003e` bit2 (`\|4`) | Запит увімкнення помпи |
| `DAT_DATA_003d` bit5 (`\|0x20`) | Фаза 2 програми декальцинації |

### Карта `DAT_DATA_004f`

| Значення | Режим | Впевненість |
| ---: | --- | --- |
| `0x00` | Вимкнено / idle після standby | висока |
| `0x01` / `0x0A` | Стартовий розігрів | висока |
| `0x02` | **Декальцинація** | висока |
| `0x03` | **Еспресо** (ready + brew) | висока |
| `0x05` | Standby / автовимкнення | середня |
| `0x08` / `0x09` / `0x0D` | Меню параметрів | висока |
| `0x0B` | Охолодження після пару → повернення в еспресо | висока |
| `0x0C` | **Пар** | висока |
| `0x0E` | Перехід/меню перед паром | висока |
| `0x0F` | Скидання налаштувань | середня |
| `0x10` | Блокування / конфлікт кнопок | середня |

## 2. Часова база (важливо для інтервалів)

У декомпіляті видно два різних «тики»:

1. **Лічильник помпи** `DAT_DATA_0031:0030` інкрементується в обробнику прапорця `DAT_DATA_0039 & 1` (і використовується як прогрес до цілі `00ba:00b9`).
2. **Countdown режимів** `DAT_DATA_0035:0034` декрементується, коли встановлено `DAT_DATA_0039 & 4` (основний крок FSM у `FUN_CODE_1825`).

`FUN_CODE_06da` (ймовірний ISR/тик) **не декомпілюється** повністю, тому період тіка №1 формально не доведений з коду осцилятора.

**Практична калібровка тіка помпи = 100 мс** добре лягає на заводські дефолти:

| Літерал | × 100 мс | Сенс |
| ---: | ---: | --- |
| `0x14` = 20 | **2,0 с** | преінфузія |
| `0x60` = 96 | **9,6 с** | 1 чашка (дефолт) |
| `0xCC` = 204 | **20,4 с** | 2 чашки (дефолт) |
| `0x0136` = 310 | **31,0 с** | макс. вікно помпи в парі |

Далі в документі секунди для помпи подані за цією гіпотезою (**впевненість висока практично, середня формально**). Підтвердження — осцилограф на лінії помпи або дизасембл `FUN_CODE_06da`.

Timer2 апаратно налаштований на **~1 мс** (`PR2=0xF9`, prescaler 1:16, `OSCCON=0x7A` → 16 МГц). Це база внутрішніх прапорців, не обов’язково 1:1 з тіком помпи.

## 3. Температура: ADC → °C

У прошивці **немає** готової таблиці «ADC → °C» у відновленому C. Перетворення нижче — інженерна оцінка за лінійною калібровкою:

- середня уставка еспресо `ADC 631 ≈ 92 °C`
- парова готовність `ADC 813 ≈ 120 °C`
- локальний масштаб ≈ **0,154 °C / count**

| ADC (dec / hex) | Орієнтовно °C | Де використовується |
| ---: | ---: | --- |
| 375 / `0x0177` | ≈ **53 °C** | декальцинація |
| 576 / `0x0240` | ≈ **84 °C** | охолодження після пару (`0x0B`) |
| 591 / `0x024F` | ≈ **86 °C** | стартовий розігрів (`0x01`) |
| 599 / `0x0257` | ≈ **87 °C** | еспресо low (`00ef=0`) |
| 631 / `0x0277` | ≈ **92 °C** | еспресо mid (`00ef=1`) |
| 663 / `0x0297` | ≈ **97 °C** | еспресо high (`00ef=2`) |
| 681 / `0x02A9` | ≈ **100 °C** | поріг у `FUN_CODE_079d` (пар) |
| 813 / `0x032D` | ≈ **120 °C** | пар ready / idle |
| 867 / `0x0363` | ≈ **128 °C** | пар під час подачі |

Впевненість °C: **середня** (залежить від NTC/дільника; абсолютна похибка може бути кілька градусів).

## 4. Режим еспресо (`DAT_DATA_004f = 0x03`)

### 4.1. Температура

Уставка формується так (`~1187–1210`):

```text
target_ADC = 0x0257 + 32 × DAT_DATA_00ef  ± корекція EEPROM-таблиці (DAT_DATA_0023)
```

| Рівень `DAT_DATA_00ef` | ADC | Орієнтовно °C |
| ---: | ---: | ---: |
| 0 (low) | 599 | ≈ 87 |
| 1 (mid) | 631 | ≈ 92 |
| 2 (high) | 663 | ≈ 97 |

Додатково `DAT_DATA_0023` додає/віднімає поправку з program-memory таблиці (`FUN_CODE_07ab`) — точні байти таблиці в C не відновлені.

Гістерезис утримання: порівнюється поточний ADC з `target−0x1F` / `target+8` тощо (`~1349–1370`) — типова зона близько **±3…5 °C** навколо уставки (оцінка).

### 4.2. Підстани brew (`DAT_DATA_004d`)

| `004d` | Дія |
| ---: | --- |
| 0 | Ready (очікування кнопки 1/2) |
| 1 | Старт порції, скидання таймерів |
| 2 | **Преінфузія** — помпа ON |
| 3 | Перехід / постановка аварійного timeout |
| 4 | **Основний пролив** |
| 5…8 | Завершення, реакція на кнопку, програмування об’єму |
| 9 | Повернення в ready |

Вибір 1/2 чашки: `DAT_DATA_0037 = 0/1` (`~4071–4087`).

### 4.3. Інтервали помпи

| Фаза | Літерал | Час @ 100 мс/тік | Пауза |
| --- | ---: | ---: | --- |
| Преінфузія ON | `00b9=0x14` (20) | **2,0 с** | — |
| Перехід `004d=2→3→4` | немає окремого countdown паузи | лише FSM-крок | **окремої багатосекундної паузи в коді немає** |
| Пролив 1 cup (дефолт) | `0122:0121 = 0x0060` (96) | **9,6 с** ON | до кінця цілі / стоп кнопкою |
| Пролив 2 cup (дефолт) | `0124:0123 = 0x00CC` (204) | **20,4 с** ON | до кінця цілі / стоп кнопкою |
| Аварійний timeout brew | `01ed:01ec = 0x0258` (600) | **60 с** | захист |

Дефолти об’єму/часу завантажуються в `FUN_CODE_06c5` (`~2093–2096`). Користувач може перепрограмувати утриманням кнопки; ліміти збереження: min `0x41` (65 → 6,5 с), max `0x02BC` (700 → 70 с).

**Висновок по паузі преінфузії:** на відміну від Arduino-репліки (2 с ON + 2 с OFF), у штатному FSM після преінфузії йде короткий перехідний підстан, а не зафіксований countdown паузи. Фактична «пауза» = час між зупинкою помпи після цілі `20` і стартом основного проливу (зазвичай частки секунди…1 тік FSM).

Джерела: `~1220–1234`, `~1290–1340`, `~2093–2096`.

## 5. Режим пару (`DAT_DATA_004f = 0x0C`)

### 5.1. Підстани

| `004d` | Дія |
| ---: | --- |
| 0 | Короткий вихід / завершення |
| 1 | Розігрів до steam-ready (`FUN_CODE_079d`) |
| 2 | Ready: очікування відкриття ручки пари |
| 3 | Подача пари: помпа ON, підвищена уставка |
| 4 | Очікування закриття ручки |
| 5 | Вихід → охолодження / normal |

Вхід у пар часто через `004f=0x0E` → `0x0C` (`~1153–1157`).

### 5.2. Температура

| Стан | ADC | Орієнтовно °C | Код |
| --- | ---: | ---: | --- |
| Ready / idle (`FUN_CODE_079d`) | `0x032D` = 813 | ≈ **120** | `~2272–2274` |
| Активна подача (`004d=3`) | `0x0363` = 867 | ≈ **128** | `~1056–1058` |
| Поріг «вже гаряче» у `079d` | `0x02A9` = 681 | ≈ **100** | `~2265–2267` |

Під час подачі уставка вища за ready — термоблок догрівається під відбір тепла парою.

### 5.3. Інтервали помпи

| Фаза | Літерал | Час @ 100 мс/тік | Пауза |
| --- | ---: | ---: | --- |
| Помпа під час відкритої ручки | `00ba:00b9 = 0x0136` (310) | **до 31,0 с** безперервно | стоп раніше, якщо ручку закрито |
| Timeout розігріву пару | `0035:0034 = 0x012C` (300) | залежить від тіка FSM (~18 с @ 60 мс або ~30 с @ 100 мс) | — |

**Імпульсного циклу ON/OFF** на кшталт `500 мс / 1000 мс` у відновленому FSM **не знайдено**. У доступному коді парова помпа виглядає як **одне безперервне вікно** до 31 с (або до закриття ручки). Модуляція всередині `FUN_CODE_06da` теоретично можлива, але не підтверджена.

Джерела: `~1031–1095`, `~2256–2274`.

### 5.4. Охолодження (`004f = 0x0B`)

Після пару ціль скидається до `0x0240` (≈84 °C) або утримання еспресо-уставки; далі перехід назад у `004f=0x03`.

## 6. Режим декальцинації (`DAT_DATA_004f = 0x02`)

### 6.1. Температура

```text
DAT_DATA_002f:002e = 0x0177   // 375 ADC ≈ 53 °C
```

Тобто декальцинація йде на **помітно нижчій** температурі, ніж еспресо/пар (`~815–817`).

Програма двофазна: прапорець `DAT_DATA_003d & 0x20`.

- Фаза 1: прапорець = 0  
- На кроці `004d=0x0B` прапорець ставиться, послідовність йде знову  
- Фаза 2: прапорець = 1; фініш на `004d=0x0C`

Частина кроків просувається кнопкою (`004b==1` → `004d++`, скидання `0030:0031`, `~4215–4218`).

### 6.2. Інтервали помпи — фаза 1 (`003d.5 = 0`)

| Крок `004d` | Літерал цілі | ON @ 100 мс/тік |
| ---: | ---: | ---: |
| 2 | 10 | **1,0 с** |
| 3 | `0x82` = 130 | **13,0 с** |
| 4 | 200 | **20,0 с** |
| 5 | `0x32` = 50 | **5,0 с** |
| 6 | 50 | **5,0 с** |
| 7 | 50 | **5,0 с** |
| 8 | 50 | **5,0 с** |
| 9 | 50 | **5,0 с** |
| 10 | 50 | **5,0 с** |

Сума ON фази 1 ≈ **64 с**.

Між кроками **немає** окремих багатосекундних pause-таймерів: пауза = зупинка помпи після досягнення цілі + перехід FSM / очікування кнопки.

Є внутрішні цикли повтору: лічильники `DAT_DATA_00c6` (`'#'` = 35) і `DAT_DATA_0159` (=4) повертають виконання на попередні кроки (`~4205–4212`) — тобто частина 5-секундних промивок може повторюватись.

### 6.3. Інтервали помпи — фаза 2 (`003d.5 = 1`)

| Крок `004d` | Літерал цілі | ON @ 100 мс/тік |
| ---: | ---: | ---: |
| 2 | 10 | **1,0 с** |
| 4 | `0x047E` = 1150 | **115,0 с** |
| 6 | `0x00FA` = 250 | **25,0 с** |
| 7 | `0x03B6` = 950 (`FUN_CODE_07d0(0xB6)`) | **95,0 с** |

Сума ON фази 2 ≈ **236 с**.

**Разом активної роботи помпи двох фаз ≈ 300 с (~5 хв)**, без урахування очікування користувача, перевірок бачка/потоку та повторів фази 1.

Джерела: `~814–914`, `~2324–2340`, `~4188–4224`.

### 6.4. Контроль потоку під час декальцинації

`FUN_CODE_0886` періодично перевіряє приріст `0031:0030`:

- фаза 1: вікно `0x14` (20 тіків ≈ 2 с)
- фаза 2: вікно `0x0A` (10 тіків ≈ 1 с)

Якщо приріст замалий — виставляються прапорці помилки/блокування (`~2609–2632`).

## 9. Невизначеності / що перевірити на стенді

1. **Період тіка `0030:0031`** — підтвердити осцилографом (очікування 100 мс).
2. **NTC → °C** — звірити MAX6675 на термоблоці з ADC-уставками 631/813.
3. **Чи є мікро-ШІМ пари в `FUN_CODE_06da`** — зараз не видно в FSM.
4. **Точна тривалість міжкрокових пауз декальцинації** — залежить від кнопки користувача і повторів `00c6`/`0159`.
5. **EEPROM-корекція** уставки еспресо (`FUN_CODE_07ab`) — зміщує ADC relative до `0x0257+32×level`.
