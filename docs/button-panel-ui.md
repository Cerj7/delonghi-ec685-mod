# Button Panel UI (`scripts/011_button_panel_ui.cpp`)

Робоча прошивка Nano на панелі кнопок: сканує 3 кнопки, керує 4 LED за командами основної плати. Контракт кадрів — [`button-panel-protocol.md`](button-panel-protocol.md).

Тестова пара на основній Nano — [`scripts/012_main_panel_link.cpp`](../scripts/012_main_panel_link.cpp).

| Пункт | Реалізація |
| --- | --- |
| Старт | усі LED **вимкнені** |
| Кнопки | фронт натискання → `B1` / `B2` / `B3` на основну |
| LED | лише за командами `HE*` / `P*` / `HS*` / `SS*` / `DC*` |
| Мультиплекс | до 4 LED «одночасно» — по одному на такт ~5 мс |
| Мигання | 300 мс on / 300 мс off |
| LED4 | мигає при `DC1`, якщо немає проливу еспресо / нагріву пару / подачі пару |
| UART | `D6→D9`, `D5←D8`, `19200` |
| USB | `115200`, ті самі коди локально + `S` (статус) |
| Watchdog | 2 с |

Апаратне читання кнопок — як у `007` / `010`: зовнішні стягуючі резистори на `D4` і `D10`, джерело `HIGH` на спільному вузлі.

---

## Піни

| Пін плати | Функція | Nano панелі |
| --- | --- | --- |
| Pin 1 | аноди LED3 / LED4 | `D7` |
| Pin 2 | аноди LED1 / LED2 + вузол кнопок | `D8` |
| Pin 3 | катоди LED1 / LED3 | `D9` |
| Pin 4 | катоди LED2 / LED4 + «пар» | `D10` |
| Pin 5 | «1 еспресо» | `D4` |
| Pin 6 | «2 еспресо» / джерело «пар» | `D12` |
| — | UART TX | `D6` → `D9` основної |
| — | UART RX | `D5` ← `D8` основної |

> ⚠️ Шлейф від’єднати від штатного `J8`. Спільний `GND` тільки між двома Nano, **не** зі штатною платою кавоварки.

---

## Поведінка LED (коротко)

1. `HE1` → LED1+LED2 мигають; `HE0` → обидва постійно.
2. `P11`/`P10` → LED1 мигає / постійно (під час проливу `B1`/`B2`/`B3` все одно йдуть на основну).
3. `P21`/`P20` — те саме для LED2.
4. `HS1`/`HS0` → LED3 мигає / постійно (нагрів пару).
5. Повторне `B3` після `HS0` → основна шле `SS1`/`SS0` → знову мигання / постійно.
6. `DC1` → LED4 мигає, якщо не йде пролив і не йде пар (нагрів/подача); `DC0` гасить.

---

## Стенд із `012`

1. Залити `011` на Nano панелі, `012` — на «основну».
2. З’єднати `D6↔D9`, `D5↔D8`, `GND`.
3. У Monitor основної: `HE1` → почекати → `HE0` — має піти нагрівна індикація.
4. Натиснути «1 Еспресо»: з’явиться `← панель BTN 1`, у режимі `A` (за замовчуванням) основна сама відповість `P11` і через 3 с `P10`.
5. `DC1` під час простою — LED4 мигає; під час `P11` — гасне; після `P10` — знову мигає; `DC0` — остаточно гасне.
6. `M` на основній вимикає авто-відповіді — далі лише ручні коди.

## Відмінність від `007` / `009`

| | `007` / `009` (тестери) | `011` (UI) |
| --- | --- | --- |
| Спокій | «бігучий вогник» | усі LED вимкнені |
| Натискання | локально тримає LED 2 с | лише шле `B?` на основну |
| RX від основної | вимкнений | слухає команди протоколу |
| Кілька LED | один активний | мультиплекс за станом |
